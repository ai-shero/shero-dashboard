Not apps — the rails around them

shero-ai-config policy repo

The canonical company AI rulebook — CLAUDE.md, skills, prompts. An admin merge here is official adoption. Sets the hard rules: PR-only to main, email via Resend (Render blocks SMTP), brand red #DA0046, never pink.

shero-team-vault knowledge

An Obsidian vault of SOPs, briefs, brand & meeting notes. Its boundary map: GitHub = code & AI, vault = knowledge, Drive = media, password manager = every secret, no exceptions.

Worth knowing
  • 01POS sits on a different Render account than the other five — so the free-tier hour exhaustion that can suspend the SHERO-workspace apps monthly doesn't touch the till.
  • 02Each app has its own Turso database. There's no shared DB — CRM and Inventory reach across by API and scraper, never by joining tables.
  • 03This dashboard is the odd one out: it deploys from master, not main, and has no server-side auth yet (a feat/auth branch is unmerged).
  • 04Brand colour is nearly unified on #DA0046 — CRM's UI is the last hold-out still on #e63946.
